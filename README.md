# Northstar Login UI

Simple vanilla HTML, CSS, and JavaScript login and registration screens.

The login page includes two local demo accounts:

- Admin: `robmalik191@gmail.com` / `R0bmalik_n1`
- User: `robmalik19@gmail.com` / `R0bm4l1k1_n1`

These credentials are for this client-side demo only. Do not use this authentication pattern for production.

## Run locally

From this folder, run:

```powershell
node server.js
```

Then open http://localhost:8000 in your browser. Use `Ctrl+C` in the terminal to stop the server.
